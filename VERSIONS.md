# ShakaTech - Website Versions

This project contains 3 different versions of the ShakaTech website, all using the same brand color scheme.

## Color Palette
- Cyan: #00E6FF
- Blue: #007BFF
- Dark BG: #0B1220
- Darker BG: #121820
- Light Gray: #E0E0E0

## Fonts
- Primary: Orbitron
- Secondary: Raleway

## Versions

### Version 1 - Classic Layout (Current Main Site)
- Traditional top navigation
- Full-width hero section
- Grid-based service cards
- Standard footer
- **Location:** `/` (root) or `/versions/v1/`

### Version 2 - Sidebar Navigation
- Left sidebar navigation
- Split hero with floating cards
- List-based services with numbers
- Modern minimal design
- **Location:** `/versions/v2/`

### Version 3 - Full-Screen Sections
- Minimal top nav
- Full-screen scrolling sections
- Large typography focus
- Slide-style presentation
- **Location:** `/versions/v3/`

## How to View

Open any of these files in your browser:
- Version 1: `index.html` (main) or `versions/v1/index.html`
- Version 2: `versions/v2/index.html`
- Version 3: `versions/v3/index.html`

All versions are optimized for desktop/laptop viewing with mobile responsive support.
